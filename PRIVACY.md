# Privacy Policy / 隐私政策

## English

Typing Garden is designed to work offline for children and families.

### Data Stored

The app stores profile names, lesson progress, best scores, and mistake history
in local application storage on the current Mac. This data is used only to
restore the local practice experience.

### Data Not Collected

Typing Garden does not provide accounts, advertising, telemetry, remote
analytics, cloud synchronization, or online leaderboards. The application code
does not transmit profile or practice data to the developer.

The app does not initialize Electron crash reporting and does not perform
automatic update checks.

### Deleting Data

Delete an individual profile with the delete-profile control in the app. To
remove all data, quit Typing Garden and delete:

```text
~/Library/Application Support/Typing Garden/
```

### Children's Privacy

Parents and guardians should avoid using a child's full legal name as a local
profile name. No profile data needs to be submitted to use the app.

### Contact

Privacy questions may be opened as a GitHub issue when they contain no personal
information. Sensitive reports should use the private process described in
[SECURITY.md](SECURITY.md).

## 中文

Typing Garden 面向儿童和家庭，默认离线运行。

### 本地保存的数据

应用会在当前 Mac 的本地应用数据中保存档案名称、课程进度、最佳成绩和错字
记录。这些数据只用于恢复本机练习状态。

### 不收集的数据

Typing Garden 不提供账号、广告、遥测、远程分析、云同步或在线排行榜。应用
代码不会把档案或练习数据传输给开发者。

应用不会初始化 Electron 崩溃报告，也不会自动检查更新。

### 删除数据

可以使用应用内的删除档案控件移除单个档案。如需删除全部数据，请退出
Typing Garden 并删除：

```text
~/Library/Application Support/Typing Garden/
```

### 儿童隐私

建议家长不要把孩子的完整法定姓名用作本地档案名。使用应用不需要提交任何
档案信息。

### 联系方式

不包含个人信息的隐私问题可以通过 GitHub Issue 提交。敏感内容应按照
[SECURITY.md](SECURITY.md) 中的私密流程报告。
